Como colaborar

  1. Abra um bloco em Análise de dados para sugerir mudanças, editar, consultar referências ou pedir revisão com IA.
  2. Confira a proposta da IA antes de aceitá-la. Salve o bloco quando estiver pronto. Para atualizar o PDF, use Gerar PDF no cabeçalho.
  3. Use Levar para o manuscrito para copiar o texto do editor e as referências para a seção escolhida.
  4. Na mesa publicada, entre com GitHub para salvar e compartilhar as alterações com os coautores.
